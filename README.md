# 🐾 Paws & Preferences

A swipe-based web application that helps users discover their cat preferences using images from the Cataas API.

Inspired by Tinder-style interactions, users can swipe right to like and left to dislike cats, then view a summary of their favorites.

---

## 🚀 Live Demo

👉 https://liaarfira.github.io/paw-and-preferences/

---

## 📸 Features

- ✅ Swipe right to Like ❤️
- ✅ Swipe left to Dislike ❌
- ✅ Tinder-style UI buttons
- ✅ Touch, mouse, and keyboard support
- ✅ Undo last swipe
- ✅ Progress indicator
- ✅ Summary of liked cats
- ✅ Dark mode
- ✅ Mobile-first responsive design
- ✅ iOS & Android viewport fixes
- ✅ Help / instruction modal

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (Responsive Design)
- JavaScript (ES6+)
- React 18 (CDN)
- Babel (In-browser transpiler)
- Cataas API (Cat Images)

---

## ⌨️ Controls

| Action      | Method                     |
|-------------|----------------------------|
| Like        | Swipe Right / → / ❤️ Button |
| Dislike     | Swipe Left / ← / ❌ Button  |
| Undo        | Z Key / ↩️ Button           |
| Dark Mode   | D Key / 🌙 Button           |
| Help        | ? Button                   |

---

## 📱 Mobile Support

- Optimized for Android and iOS
- Supports dynamic viewport height
- Safe-area inset support for notched devices
- Momentum scrolling enabled
